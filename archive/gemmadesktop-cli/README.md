# ARCHIVED: gemmadesktop-cli

Status: archived / not maintained.

This directory is a legacy Gemma Desktop CLI experiment kept for historical reference only. It is not an active Open Gemma product, is not part of the active npm workspace, and should not receive feature work unless the project is explicitly unarchived later.

Use these active paths instead:

- `gemma-cli/` for the maintained terminal coding-agent product.
- `gemma-desktop/` for the maintained Electron desktop product.
- `gemma-sdk/` for shared SDK contracts, runtime adapters, tools, prompts, tracing, attachment handling, and cross-product behavior.

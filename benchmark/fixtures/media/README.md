# Media Benchmark Fixtures

These files are small, sourceable media fixtures used by the image-description and audio-transcription benchmark scripts.

The scripts can download the fixture files when they are missing. Keep this README in sync with the fixture definitions in `../../gemma-media-benchmark-core.mjs`.
